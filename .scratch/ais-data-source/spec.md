# AIS 数据源接入与船体展示

## 范围与默认值

后端固定项目 `tianjin-lock / 天津船闸`，配置数据源 `tianjin-lock-ais / 天津船闸 AIS` 和 `dagu-ais / 大沽 AIS`，上游分别为 `ws://192.168.1.20:4323/websocket` 和 `ws://192.168.1.21:5345/websocket`，均使用 `seaoil-ais` 适配器消费 `api=1`。天津船闸位于来源目录首位，保持首次选择的默认来源。项目身份、来源地址、适配器和估算参数集中在后端配置中；前端只使用来源目录与统一数据，不编辑来源地址。

监控页面一次选择一路数据源，浏览器按项目记住选择，刷新恢复；无记忆时选择第一路，明确关闭后保持关闭，失效的旧来源选择回退为关闭。切换摄像头保留来源选择，清除上一摄像头的追踪状态。离开三维页面或进入历史截图时关闭页面订阅并隐藏实时船舶，返回实时重新获取快照，不把当前 AIS 当作历史同期数据。

AIS 场景显示所选来源的全部有效实时目标，不按摄像头 PTZ/FOV、距离或自定义椭球遮挡筛选，无有效 PTZ 回读时仍显示点。用户开启追踪后，在位置、船艏或回退 COG 变化时持续重新定位；默认每次调用结束等待 2 秒检查最新状态。模拟船高默认 10 米。项目名、时间解释、高度和过期时间都是部署配置，不能表述为已验证的源事实。

## 统一模型与来源适配

单船只包含 `mmsi`、`time`、`longitude`、`latitude`、`heading`、`cog`、`length`、`width`、`speed` 九个字段。`heading` 为船艏向，`cog` 为对地航向，分别保留原始业务语义。时间输出带时区的 ISO 字符串；本源无偏移的时间按后端固定 UTC+08:00 解释。经纬度为 WGS84 十进制度，方向为真北顺时针度，尺寸单位米，速度单位节。

MMSI 保留九位字符串；没有有效身份、时间或位置的记录跳过，并在来源状态中暴露计数与错误。针对本源船艏误报为 0 的问题，船艏为 0 时保留同船当前缓存中尚未过期的旧船艏，没有旧值时为 `null`；其他字段照常更新，后续有效非零船艏可以替换旧值。旧船艏随目标过期或来源断开清除。其他无效船艏向（包括 456/511）、非正长宽及不可用速度输出 `null`；0 节速度保留。`cog` 只接受 0～360°左闭右开的有限度数，北向 0°有效，360、缺失及其他无效值输出 `null`。COG 独立保存，仅在船艏缺失时参与船体建模，不写入 `heading`。保留输入经纬度，不向统一记录增加船名、供应商字段或假装实测的 ABCD。

两路来源均只消费 `api=1` 的船舶批次，其他消息类别不进入 AIS 目标。在各来源内按 MMSI 合并，不合并不同来源的同 MMSI 船舶，不用空批或未出现在一批中的目标触发删除；同一身份优先较新来源时间，同时间采用后收到的有效记录。来源时间晚于后端时钟超过一分钟的记录跳过。最新位置在来源时间超过 10 分钟后过期；初始查询可能包含最近 60 分钟记录，过期数据不因此重新变为新鲜数据。实时目标不写数据库。

后端共享各来源的一个上游连接，按需启动；连接断开立即清除当前目标并公开异常，指数退避重连（2 秒起、30 秒封顶），重连从空状态接收初始数据。连接建立超时 10 秒，90 秒没有任何消息时重建连接；环境状态也可证明传输有活动。服务关闭清理连接、重试、清理定时器与下游订阅。

## 前后端接口

- `GET /api/data-sources`：返回项目身份、来源目录和展示估算参数，不返回上游地址或供应商报文。
- `GET /api/data-sources/:id/snapshot`：返回当前来源状态、错误、接收时间和完整目标快照，用于初始获取及实时定位前刷新；预判模式使用前端缓存。
- `GET /api/data-sources/:id/events`：使用 SSE 发布同样的统一完整快照；浏览器自动重连，每次连接重新取得完整状态。上游仍为 WebSocket。单向下游使用现有 HTTP 能力，不新增依赖。

SSE 更新合并短时间内的批次，发送心跳；慢客户端只保留一份待发的最新快照，避免无界堆积。切源与重连后不接受旧来源回调覆盖当前状态；下游断开时清理报告点并结束实时追踪，已开启的预判使用缓存继续外推；恢复后以新快照校正起点。

页面以事件监听注册订阅回调，兼容代理包装的 EventSource 原生实例；初始化异常时关闭已创建的流，清除目标与追踪，显示具体原因和可重试的“连接失败”，不滞留于“正在连接”。HTTP 回归包含实际页面消费服务经过代理环境的订阅和恢复，不增加组件测试。

## 几何与页面操作

AIS 单次定位、持续追踪和预判按目标坐标求指向，海平面视距外的目标也可参与计算。实际下发沿用精确定位接口的设备范围校验。

默认关闭“使用 ABCD 船体居中”，普通及当前追踪船都在原始报告位置显示点。定位以 AIS 经纬度的零高程点作为画面中心，不使用天线偏移、船高、船长宽或船艏。跟踪倍率 Z 由用户手动填写并点击“应用倍率”，单次定位和持续追踪均原样使用该值；未设置时沿用该次 PTZ 回读的 Z。应用及实际下发均校验有限数字、Z 不小于 1 且不超过当前摄像头已保存的最大 Z，超限明确报错，不自动裁剪或取整。ABCD 只影响瞄准点与船体展示，距离、FOV、船体尺寸不参与 AIS 倍率计算。模式与自定义倍率保存在当前网页内存，切船、切源和切摄像头后沿用；切到倍率上限更低的摄像头时须重新填写合法倍率，刷新恢复为沿用当前回读。

开启 ABCD 后，只有当前追踪船尝试建立长方体，根据有效船长宽及来源参数估算 ABCD：`A=0.9L`、`B=0.1L`、`C=D=0.5W`，默认船高 10 米。前端船体尺寸表单允许手动设置 ABCD 及船高并恢复估算。A/B/C/D 分别表示 AIS 报告位置至船艏、船艉、左舷、右舷的米制距离，均须有限且非负；A+B、C+D 及船高须有限且大于 0。手动尺寸按数据源与 MMSI 保存在当前网页内存，关闭 ABCD、AIS 更新、切源或切换摄像头后保留，刷新或关闭网页后清除，不修改原始 AIS 长宽和位置、不写后端或浏览器存储。

船体方向优先采用有效船艏，船艏缺失时采用有效 COG；来源 0 船艏过滤后保留的有效旧船艏仍优先使用。该方向结合当前估算或手动尺寸生成长方体，供显示及中心定位共用；手动尺寸可补足来源缺失的长宽。船体尺寸标题旁的问号支持鼠标悬停、聚焦或点击，展示 AI 生成的 ABCD／船高示意图，标明 AIS 天线、船艏、船艉、左舷、右舷及海面以上的模型高度。船长宽为 A+B 与 C+D，模型中心相对报告位置沿选用方向移动 `(A-B)/2`、向其右侧移动 `(D-C)/2`，底面在零高程，盒中心高度为船高的一半。默认估算前移 `0.4L`，偏移使用局部地理坐标转换，不把米直接加到经纬度。船艏和 COG 均不可用时使用报告点。

AIS 场景按所选来源的完整有效实时目标创建对象，不额外进行空间筛选。盒面和轮廓在视频合成后的 Overlay 队列绘制，保留完整观察投影与正常点选通道，避免透明绘制回退时被视频覆盖。历史模式、离页或关闭来源时清理全部目标；来源断开时清理报告点，已开启预判的当前船继续显示推算位置。缺少有效尺寸，或船艏与 COG 均不可用时降级为报告点，不伪造船体大小。

点选船舶或按 MMSI 查找后显示精简详情。地图处于“固定观察”时，单击 AIS 点会选择该船、结束当前 AIS 持续追踪，并复用现有定位流程下发一次 P/T/Z；“跟随摄像头”时只选择并显示详情。单次定位不启用定时追踪，后续 AIS 更新不会重复下发；摄像头和安装参数有效、回读未过期且当前没有保存、控制或扫描占用时才允许定位。等待期间切源、切摄像头、改选目标、恢复跟随、进入历史、离页或修改取景参数，会使尚未下发的旧请求失效。点击“开始追踪”立即定位，此后每次调用结束等待 2 秒检查最新船舶状态；经纬度、船艏或船艏缺失时的 COG 变化会重新定位，来源时间、速度及长宽变化不单独触发，本源过滤后的 0 船艏也不单独触发。切换 ABCD 模式、应用跟踪倍率、应用手动尺寸或恢复估算，使旧参数下未下发的请求失效，旧回调不能清除新追踪；正在持续追踪时按新参数重新定位。调用串行，期间多次更新只使用最新状态。每次先回读摄像头 PTZ，完成后再取来源快照，复用现有原始 P/T 反算与精确定位接口；默认瞄准报告点，开启 ABCD 且尺寸与选用方向有效时瞄准当前船体中心，中心高度取当前采用船高的一半，缺少几何时使用报告点。P/T 按安装模型反算，Z 使用已应用的自定义倍率或该次回读值，并校验摄像头已保存的最大 Z。

点击“预判”开启独立的连续定位模式。预判秒数默认 3，允许任意可计算的非负秒数及小数，0 表示推算当前时刻；每次定位结束等待 2 秒，再根据当前浏览器时刻外推，复用 PTZ 回读和精确定位接口，不等待 AIS 更新或来源快照接口。时间跨度为当前时刻到 AIS 记录时刻的差加预判秒数，距离为 `航速（节）×1852/3600×时间跨度`；沿 COG 优先、有效船艏回退的方向，在 WGS84 椭球上匀速恒向外推。0 航速保持报告位置，不要求方向。历史报告与计算结果分别保存，不逐帧累加或改写原始 AIS 坐标。

预判起点缓存在当前页面。新 AIS 到达后，以相同或更新源时间的记录校正起点，较旧记录不回退；来源断开、SSE 异常或目标从实时列表过期时保留所选船舶和预判缓存，继续按时间外推。普通报告点按实时来源状态清理，地图只为当前预判船显示推算位置及“预判”标签。每次成功下发后在面板显示预判位置和目标时刻，ABCD 与手动倍率继续沿用。再次点击“预判”应用新的秒数，使旧请求失效；“开始追踪”切回实时模式。缺少有效运动数据、时间或坐标不可计算、PTZ 定位失败时明确报错并停止，不自动重发或生成伪造位置。

停止追踪在等待回读时也可操作。停止、手动方向／变倍／精确定位、保存配置、启动截图扫描、切源、切换摄像头、进入历史、离页、隐藏网页或改选目标会结束实时或预判跟踪，使尚未下发的旧请求失效；选择世代单调增加，重新选择同船也不恢复旧请求。实时追踪在目标过期或来源断开时结束；预判继续使用缓存记录。两种模式失败后均需用户显式重新开启，追踪状态、缓存和定时器不持久化；已经下发的命令仍以真实回读和现场为准。
