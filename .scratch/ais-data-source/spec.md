# AIS 数据源接入与船体展示

## 范围与默认值

用户已要求进入实现。后端固定项目 `tianjin-lock / 天津船闸`，配置数据源 `tianjin-lock-ais / 天津船闸 AIS`，上游为 `ws://192.168.1.20:4323/websocket`。项目身份、来源地址、适配器和估算参数集中在后端配置中；前端只使用来源目录与统一数据，不编辑来源地址。

监控页面一次选择一路数据源，浏览器按项目记住选择，刷新恢复；无记忆时选择第一路，明确关闭后保持关闭，失效的旧来源选择回退为关闭。切换摄像头保留来源选择，清除上一摄像头的追踪状态。离开三维页面或进入历史截图时关闭页面订阅并隐藏实时船舶，返回实时重新获取快照，不把当前 AIS 当作历史同期数据。

AIS 显示不设距离上限，最佳观察、跟随和固定观察均按当前摄像头真实 PTZ/HFOV/VFOV 筛选；近处普通点保留。用户开启追踪后，在位置或船艏变化时持续重新定位；默认每次调用结束等待 1 秒检查最新状态。模拟船高默认 10 米。项目名、时间解释、高度和过期时间都是部署配置，不能表述为已验证的源事实。

## 统一模型与来源适配

单船只包含 `mmsi`、`time`、`longitude`、`latitude`、`heading`、`length`、`width`、`speed` 八个字段。时间输出带时区的 ISO 字符串；本源无偏移的时间按后端固定 UTC+08:00 解释。经纬度为 WGS84 十进制度，方向为真北顺时针度，尺寸单位米，速度单位节。

MMSI 保留九位字符串；没有有效身份、时间或位置的记录跳过，并在来源状态中暴露计数与错误。针对本源船艏误报为 0 的问题，船艏为 0 时保留同船当前缓存中尚未过期的旧船艏，没有旧值时为 `null`；其他字段照常更新，后续有效非零船艏可以替换旧值。旧船艏随目标过期或来源断开清除。其他无效船艏向（包括 456/511）、非正长宽及不可用速度输出 `null`；0 节速度保留，不以 COG 替代船艏向。保留输入经纬度，不向统一记录增加船名、供应商字段或假装实测的 ABCD。

按本地来源实现只消费 `api=1` 的船舶批次，其他消息类别不进入 AIS 目标。按 MMSI 合并，不用空批或未出现在一批中的目标触发删除；同一身份优先较新来源时间，同时间采用后收到的有效记录。来源时间晚于后端时钟超过一分钟的记录跳过。最新位置在来源时间超过 10 分钟后过期；初始查询可能包含最近 60 分钟记录，过期数据不因此重新变为新鲜数据。实时目标不写数据库。

后端共享各来源的一个上游连接，按需启动；连接断开立即清除当前目标并公开异常，指数退避重连（2 秒起、30 秒封顶），重连从空状态接收初始数据。连接建立超时 10 秒，90 秒没有任何消息时重建连接；环境状态也可证明传输有活动。服务关闭清理连接、重试、清理定时器与下游订阅。

## 前后端接口

- `GET /api/data-sources`：返回项目身份、来源目录和展示估算参数，不返回上游地址或供应商报文。
- `GET /api/data-sources/:id/snapshot`：返回当前来源状态、错误、接收时间和完整目标快照，用于初始获取和每次定位前刷新。
- `GET /api/data-sources/:id/events`：使用 SSE 发布同样的统一完整快照；浏览器自动重连，每次连接重新取得完整状态。上游仍为 WebSocket。单向下游使用现有 HTTP 能力，不新增依赖。

SSE 更新合并短时间内的批次，发送心跳；慢客户端只保留一份待发的最新快照，避免无界堆积。切源与重连后不接受旧来源回调覆盖当前状态；下游断开时隐藏目标和禁止追踪，恢复后以新快照为准。

页面以事件监听注册订阅回调，兼容代理包装的 EventSource 原生实例；初始化异常时关闭已创建的流，清除目标与追踪，显示具体原因和可重试的“连接失败”，不滞留于“正在连接”。HTTP 回归包含实际页面消费服务经过代理环境的订阅和恢复，不增加组件测试。

## 几何与页面操作

普通船舶使用报告位置上的点。只有当前追踪船尝试建立长方体；默认根据有效船长宽及来源参数估算 ABCD：`A=0.9L`、`B=0.1L`、`C=D=0.5W`，默认船高 10 米。前端船体尺寸表单允许手动设置 ABCD 及船高并恢复估算。A/B/C/D 分别表示 AIS 报告位置至船艏、船艉、左舷、右舷的米制距离，均须有限且非负；A+B、C+D 及船高须有限且大于 0。手动尺寸按数据源与 MMSI 保存在当前网页内存，AIS 更新、切源或切换摄像头后保留，刷新或关闭网页后清除，不修改原始 AIS 长宽和位置、不写后端或浏览器存储。

有效船艏结合当前采用的估算或手动尺寸生成长方体；手动尺寸可补足来源缺失的长宽。船体尺寸标题旁的问号支持鼠标悬停、聚焦或点击，展示 AI 生成的 ABCD／船高示意图，标明 AIS 天线、船艏、船艉、左舷、右舷及海面以上的模型高度。船长宽为 A+B 与 C+D，模型中心相对报告位置沿船艏移动 `(A-B)/2`、向右舷移动 `(D-C)/2`，底面在零高程，盒中心高度为船高的一半。默认估算前移 `0.4L`，偏移使用局部地理坐标转换，不把米直接加到经纬度。

视场过滤先于场景对象创建，兼顾追踪盒的体积边界；地球遮挡按原有椭球规则处理。盒面和轮廓在视频合成后的 Overlay 队列绘制，保留完整观察投影与正常点选通道，避免透明绘制回退时被视频覆盖。无有效 PTZ/FOV、历史模式、离页或来源断开时不绘制 AIS。缺少有效尺寸或船艏向时降级为报告点，不伪造船体大小。

点选船舶或按 MMSI 查找后显示精简详情。点击“开始追踪”立即定位，此后每次调用结束等待 1 秒检查最新船舶状态；经纬度或船艏变化时重新定位，来源时间、速度及长宽变化不单独触发，本源过滤后的 0 船艏也不单独触发。追踪期间应用手动尺寸或恢复估算会按新参数重新定位，旧参数下未下发的请求失效，旧回调不能清除新追踪。调用串行，期间多次更新只使用最新状态。每次先回读摄像头 PTZ，完成后再取来源快照，复用现有原始 P/T 反算与精确定位接口；尺寸与船艏有效时瞄准当前船体中心，中心高度与取景长宽高均使用当前采用的估算或手动尺寸，按横纵占比均不超过 50% 估算 Z，并受摄像头已保存的最大 Z 限制，缺少几何时瞄准报告点，保留当前 Z。

停止追踪在等待回读时也可操作。停止、手动方向／变倍／精确定位、保存配置、启动截图扫描、切源、切换摄像头、进入历史、离页、隐藏网页或改选目标会结束追踪，使尚未下发的旧请求失效；选择世代单调增加，重新选择同船也不恢复旧请求。目标过期、来源断开或定位失败时结束追踪，需用户显式重新开启。追踪状态和定时器不持久化，已经下发的命令仍以真实回读和现场为准。
