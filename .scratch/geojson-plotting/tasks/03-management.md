## 工作范围

按[规格](../spec.md)实现独立标绘管理页面、导入与关联编辑、改名与删除、按摄像头显隐、地图图层面板和定位衔接，原文与可见状态在 Viewer 外保存。保持设备切换保护、识别草稿保存及现有页面行为。

负责 `src/app/app.component.ts/html/css`、`src/app/icon.component.ts`、新增管理页及必要的前端状态模块，并同步 README。统一类型和 API 方法由 API 票提供，场景接口由场景票提供；按规格先并行实现，集成后构建。用户指定前端仅构建，不新增测试，不运行浏览器。

## 实施结果

- 独立标绘管理页提供单文件 UTF-8 导入、名称草稿、摄像头多选、零关联、按上下文显隐与定位，以及确认影响范围后的整份删除。文件读取严格校验 UTF-8 并保留 BOM，导入和保存失败保留表单。
- 地图工具栏提供当前摄像头图层面板、持久显隐、定位、刷新／重试和管理入口；列表、原文缓存及错误状态由 Viewer 外的 `PlotLayerState` 管理，旧列表、详情与定位响应按代次核对。
- 定位隐藏图层先保存显示；摄像头切换沿用草稿与操作保护，切页检查识别草稿保存结果，成功后关闭跟随，不发送 PTZ。
- 已合并共享类型/API、场景及最新集成分支 `1d1f506`；`npm run build` 与差异检查通过，仅保留既有 CommonJS 依赖提示。
- 未新增前端测试；未运行浏览器、真实设备或数据目录。布局、真实 WebGL、复杂文件性能和现场精度仍待验收。
