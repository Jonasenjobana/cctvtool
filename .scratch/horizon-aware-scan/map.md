# 识别标注驱动的海天线补偿截图

Labels: wayfinder:map
Status: open

## Destination

利用普通固定 T 截图的海天线标注计算 P/Z/T 补偿计划，明确舍弃区间，预览后创建可恢复的新自动截图任务。

## Notes

- 已确认的使用约束：保留普通固定 T 截图，移除专用预扫描；从识别任务标注计算补偿，忽略图在拟合与新任务对应 P 区间均跳过。
- 当前按 implement-spec 执行[海天线标注生成补偿截图任务](spec.md)，复用已确认的公开几何和后端 API 测试边界；真实设备和现场精度仍待验收。
- 研究决策与实施任务分别保留，待定预测与现场精度不能表述为已验证。
- 使用[术语表](../../GLOSSARY.md)区分预扫描、粗标定与正式扫描；已确认的使用约束不等于粗标定已通过质量检查。
- 现有流程与接口入口：[README](../../README.md#自动扇区截图与任务)、[API](../../docs/API.md#自动扇区截图与任务接口)。本地图描述待定方案，产品文档继续描述当前有效行为。
- 本地图采用本地 Markdown 决策票：每个决策独立保存于 `issues/`，依赖记录在子票的 `Blocked by:` 行。研究文档随源码维护，分支和提交遵循 [Git 协作规范](../../CONTRIBUTING.md)。

## Out of scope

- 不执行真实设备扫描，不自动应用安装参数。
- 本任务不包含经纬度与绝对朝向的标定。
- 光学模型扩展及现场精度验收需要后续实测依据；当前未据此认定粗标定在所有目标倍率下均满足精度要求。
