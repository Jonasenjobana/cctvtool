# 高倍率自动截图的海天线保持与倾斜标定

Labels: wayfinder:map
Status: open

## Destination

形成无需预先知道安装倾斜量的自动采样方案：明确如何取得粗标定、如何随 P 调整 T 取得高倍率海天线样本，以及怎样用实际采样姿态完成最终倾斜拟合。控制规则、质量门槛与中断恢复明确后，可以进入实现。

## Notes

- 已确认的使用约束：允许低倍率预扫描；预扫海天线经人工复核后，才进行高倍率正式扫描；T 的调整目标为海天线在画面中心附近，上下保留余量。
- 当前进入 implement-spec 实现，规格与验收依据为[海天线保持自动截图实现规格](spec.md)。允许创建集成分支、分票实现、测试和代码审查，不操作真实设备，不进行浏览器调试。
- 研究决策与实施任务分别保留，待定预测与现场精度不能表述为已验证。
- 使用[术语表](../../GLOSSARY.md)区分预扫描、粗标定与正式扫描；已确认的使用约束不等于粗标定已通过质量检查。
- 现有流程与接口入口：[README](../../README.md#自动扇区截图与任务)、[API](../../docs/API.md#自动扇区截图与任务接口)。本地图描述待定方案，产品文档继续描述当前有效行为。
- 本地图采用本地 Markdown 决策票：每个决策独立保存于 `issues/`，依赖记录在子票的 `Blocked by:` 行。研究文档随源码维护，分支和提交遵循 [Git 协作规范](../../CONTRIBUTING.md)。

## Decisions so far

- [低倍率预扫如何取得可靠的粗标定](issues/01-coarse-calibration.md)：显式低倍率、多方向采样，人工复核后使用临时粗结果。
- [怎样计算并验证随 P 变化的高倍率 T](issues/02-tilt-prediction.md)：按椭球切线反求同一俯仰分支，结合实际视场与角度余量拒绝不可行计划。
- [正式扫描怎样衔接最终拟合与中断恢复](issues/03-scan-and-fit-workflow.md)：关联两阶段任务、冻结控制依据，自动识别候选并由人工应用最终参数。

## Not yet specified

粗标定与高倍率试拍出现偏差后，需要根据误差随方向、倍率变化的实际表现，再判断处理深度；目前还不能确定是否需要扩展光学模型。

## Out of scope

- 不执行真实设备扫描，不自动应用安装参数。
- 本任务不包含经纬度与绝对朝向的标定。
