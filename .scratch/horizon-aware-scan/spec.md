# 海天线标注生成补偿截图任务

Status: in-progress
Integration branch: feat-horizon-aware-scan
Base: b83f155

## 目标与已确认约束

普通自动截图保持固定 T/Z。用户从截图任务创建识别任务，标注真实海天线并忽略无效图片，在识别页计算各 P/Z 对应的 T，预览后创建新的补偿截图任务。

用户明确要求移除专用海天线预扫描。忽略或舍弃的源图既不参与拟合，也跳过其对应的 P 采样区间。目标倍率先按一任务一个 Z 实现，可换 Z 重新计算。已有原图、标注与历史任务保留；计算不会转动设备或写回摄像头安装参数。

继续使用用户已确认的公开几何接口和后端任务 API 测试边界。使用现有依赖，不进行浏览器调试、不操作真实设备。

## 计算与舍弃规则

- 复用当前四项安装参数拟合和 WGS84 海天线 T 反求；只使用未忽略、源记录与图片存在、姿态稳定、标注合法的图片。三张、三个 P 方向、30°覆盖及现有质量门槛继续生效。
- 一个计划选择 `zoom`、`panMin`、`panMax`、`panStep`、`tiltMin`、`tiltMax`。P/Z/T 都保持设备原始角度/倍率语义，T 范围为显式允许区间，不硬截越界解、不跨 0°包装负值。
- P 范围在 0～360°内，允许单 P 试拍。`panStep` 为最大 P 间隔，均匀含两端，实际间隔不大于输入值；最多 10000 个候选点，先检查数量再分配数组。
- 按来源任务的原始采样 P 点建立采样区间，相邻中心的中点作为分界。对原任务未完成、已删除、忽略或无有效标注的采样区间，新计划标记跳过，不用两侧有效图片跨越填补。优先用源任务完整目标序列/scanIndex；历史元数据不完整时保守限制在已知范围。
- 目标 P 在有效区间内才计算 T。不可达点列入 `skippedTargets` 并解释原因；有有效目标才能创建任务。T 为角度补偿，当前同轴变倍模型下同 P 的理论 T 不随 Z 成比例变化。
- 预览不猜测目标倍率 FOV。执行时按真实 HFOV/VFOV 检查，沿用角度余量 `max(0.02°,3×角度RMS)` 与 T 容差 `min(0.15°,0.05×VFOV)`；无效视场、余量不足、到位失败明确终止并保留已保存图片。

## API 契约

### 计算计划

`POST /api/recognition-tasks/:id/compensation-plan`

```json
{"revision":0,"zoom":15,"panMin":175,"panMax":295,"panStep":5,"tiltMin":0,"tiltMax":90}
```

- 来源为有截图的稳定扫描任务；接受普通固定 T 截图及补偿任务，不要求专用阶段标记。识别不能排队/运行中，版本必须一致。
- 按当前标注重新拟合、生成结果，返回更新后的 `RecognitionTask`。质量不通过时展示真实 `result`，`compensationPlan` 为 null，不能创建任务。
- 成功时在现有任务 JSON 元数据中保存 `compensationPlan`：`id/revision/resultId/createdAt/settings`、`sourceSnapshotIds`、`sourceCount/usableSourceCount/discardedSourceCount`、`targets: [{pan,tilt,zoom}]`、`skippedTargets: [{pan,zoom,reason}]` 及仅服务端使用的冻结控制标定/角度余量。
- 所有目标均跳过时计划状态为 `empty`，否则为 `ready`。不会产生自动截图任务或调用控制接口。
- 标注/忽略变化、重新生成安装参数或应用导致参考配置变化时，清除或使旧计划失效；UI 编辑目标设置也应使原预览失效。

### 创建任务

`POST /api/recognition-tasks/:id/compensation-scan`

```json
{"revision":0,"planId":"当前预览计划标识"}
```

- 校验当前计划、标注版本、拟合结果、摄像头配置版本/通道、参与源图和设备占用。过期计划、源图删除、通道/配置变化或空计划明确拒绝。
- HTTP 202 返回新 `SnapshotGroup`，冻结有效 `targets`、控制标定、来源引用、被舍弃点与角度余量。`sampleCount` 只统计有效目标；真实 `ptz/ptzAfter` 与控制目标继续分开保存。
- 新任务使用 `compensation` 元数据（`planId/sourceRecognitionTaskId/sourceRevision/sourceResultId/targetZoom/tiltMin/tiltMax/angularMarginDegrees/skippedTargets` 等），不再创建阶段型预扫描任务。
- 暂停、继续、停止失败占用、通道冲突、异常重启与已拍满任务的停止收尾沿用当前流程。修改源标注不回溯改变已经创建的任务。
- 补偿截图完成后自动关联识别并生成候选，失败隔离，不自动应用安装参数。

### 普通截图与历史数据

`POST /api/cameras/:id/snapshot-scans` 仅保留原固定 T/Z 请求，移除可选预扫描字段；移除原 `/horizon-scan` 创建路由。现有冻结任务与截图数据仍可读取和按已有控制依据恢复，不删除业务数据；必要的旧元数据读取兼容限于持久化边界。

## 前端与文档

- 实时页移除采样方式、预扫倍率和预扫 T 范围等专用字段，普通截图保持原操作。
- 识别页提供“计算 P/Z 对应 T”入口，填写目标 Z、P 范围/间隔及允许 T 区间；默认从来源任务填入已知值。先保存当前标注，显示有效/舍弃源图数量、计划 P/Z/T 和跳过原因，再提供“创建自动截图任务”。
- 计划展示分页/逐步展开，避免一次渲染 10000 行。新建成功跳到该截图任务。所有接口保留业务数值，格式化放在前端。
- 普通识别结果仍可生成和手动应用安装参数。自动识别输出与海天线真实性、实拍居中精度区分。
