# 01: 在高倍原图上查看基准海天线与像素差

**What to build:** 标定人员在已有高倍识别任务中选择同一摄像头的合格基础标定结果，在原图上同时查看人工标注和基准理论海天线，以及标注范围左端、中点和右端的有符号垂直偏差。该任务交付可独立使用的测量与复核能力，不生成安装参数候选。

**Parent:** [基础倍率与随机高倍率截图联合精修安装参数](../../horizon-vertical-drift/issues/05-high-zoom-refinement.md)

**Blocked by:** 无，可立即开始。

**Status:** resolved

- [x] 识别页面提供基础来源选择及原图对照；来源须为同一摄像头、当前版本有效的合格四参数结果，沿用历史预扫粗结果仅供查看的限制。
- [x] 理论线按所选基础结果的固定安装条件和四项参数，结合该张图的真实 P/T、HFOV/VFOV 与尺寸计算；基础倍率和 P 范围不写死为 8 倍、40～240°。
- [x] 保存和使用真实海天线的正式归一化标注，沿用已有端点编辑与横向跨度校验；不另行录入偏差数字，不移动原标注来抵消模型误差。
- [x] 原图对照显示理论线、正式标注，以及标注横向范围左端、中点和右端的偏差箭头与原图像素值。偏下为正、偏上为负，图片显示缩放不改变业务数值，标注范围外不作测量外推。
- [x] 对外测量数据包含理论线、上述有符号垂直偏差、海天线方向差、像素 RMS、角度 RMS、实际 P/T/Z、FOV、尺寸和排除原因；这些误差量分别命名，不能互相替代。
- [x] 理论线不经过对应图像竖线时返回空偏差并明确不可比较，不填零；其余几何误差如实保留。不同分辨率按实际尺寸计算，并能通过角度残差进行比较。
- [x] 切换基础来源或图片、修改并保存正式标注后，理论线和偏差更新；未保存修改沿用现有草稿处理，旧版本、过期来源和已变化的固定安装条件不能继续显示为有效测量。
- [x] 沿用现有移动样本、无效 PTZ/FOV、通道不一致和标注有效性规则，展示排除原因；不把读数稳定当作画面严格同步。
- [x] 测量请求不写入摄像头配置、正式标注或拟合结果，不调用设备运动接口；原图及其拍摄时参数副本保持原值。
- [x] 以现有识别任务 HTTP 集成测试验证真实几何计算、正负号、不同尺寸的像素与角度关系、理论线不可见、版本和来源边界；使用临时 SQLite 和实际几何模型，不断言私有算法步骤，不用页面源码字符串代替交互验证。
- [x] 维护相关功能说明、接口契约及术语引用；按项目要求完成必要接口回归和前端检查，不开展浏览器调试，不将静态或合成验证表述为现场验收。
