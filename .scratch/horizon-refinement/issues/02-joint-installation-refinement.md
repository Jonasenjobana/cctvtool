# 02: 联合基础与多批高倍截图生成精修候选

**What to build:** 标定人员在高倍主任务中选择合格基础结果和补充高倍识别任务，以基础参数为初值联合精修现有四项安装参数。页面保存候选及完整来源，提供基准与候选的参数、误差和原图理论线对照，明确处理无改进、不可可靠求解和来源过期。该任务完成候选生成与复核准备，不开放精修候选的设备配置应用。

**Parent:** [基础倍率与随机高倍率截图联合精修安装参数](../../horizon-vertical-drift/issues/05-high-zoom-refinement.md)

**Blocked by:** 01：在高倍原图上查看基准海天线与像素差。复用其原图理论线和测量契约完成候选前后对照。

**Status:** ready-for-agent

- [ ] 页面可选择一个同摄像头合格基础结果，使用当前主任务及零个或多个补充高倍任务。高倍任务不要求已有合格单任务拟合结果，但正式标注须保存且识别不在排队或执行中；高倍组至少有一张有效图片的倍率高于基础组最大参与倍率。
- [ ] 随机顺序、非等间隔 P、不同 T/Z、不同分辨率及分轮采集的数据可参与计算；不要求图片重叠、完整转圈或固定张数，逐图使用真实回读与视场角。有效样本数、倍率范围、P 覆盖和排除原因可见。
- [ ] 请求仅提交来源标识、期望正式标注版本和基础结果编号，服务端读取真实元数据与标注。不同摄像头、固定安装条件冲突、无效基础结果及同一截图标识跨来源重复时拒绝；不同时间重复拍摄的新截图允许使用。
- [ ] 冻结基础参数、固定安装条件、基础参与图以及各来源任务版本和有效图清单。计算前与保存前检查版本，失败不产生部分结果；来源清单变化使旧候选失效。
- [ ] 基础原始标注继续参与目标，仅求解 P 轴前后倾、P 轴左右倾、T 偏移和画面 Roll 修正。固定位置、高度、默认朝向和既有光学假设，复用稳健像素残差、数值求导和阻尼最小二乘，不增加倍率补偿或训练依赖。
- [ ] 图内按有效标注点数归一化；基础组与高倍组分别按有效截图数平均后等权合并。高倍图片拆分到不同任务不改变权重，有符号偏差不能直接相加以相互抵消。
- [ ] 用同一批观测给出总体、基础组、高倍组及逐图的精修前后误差，包含像素 RMS、角度 RMS、实际 P/T/Z、尺寸与垂直偏差。页面列出四项参数基准值和候选值，并能在原图对照中切换两份理论线与偏差。
- [ ] 合格候选满足现有收敛、四参数可辨识性、总体 RMS 规则，以及基础组和高倍组各自 RMS 均不超过 5 原图像素的门槛；联合稳健目标须改善，分组或逐图误差上升如实展示。
- [ ] 基准已合格且在现有终止精度内无改进时明确返回无需修正，不产生可应用的新修正；没有有效样本、未收敛、不可辨识和超差分别给出可判断原因。固定安装模型解释不了的倍率相关偏差保留残差，不自动新增参数来吸收。
- [ ] 来源选择、候选、模型版本、结果编号、诊断和全部输入版本保存在主任务扩展元数据中，刷新和服务重启可恢复；重新计算产生新编号。原单任务结果、基础结果、正式标注、原图和其他来源任务不被覆盖。
- [ ] 修改任何参与来源的正式标注或忽略状态、重新生成基础结果、删除参与图片或改变固定安装条件后，旧候选显示为过期并拒绝继续作为有效结果使用。当前相机四项修正与基准值不同不替换所选初值；后续应用所需的生成时设备配置版本须记录完整。
- [ ] 生成和预览均不写摄像头配置、不调用设备运动接口，不新增自动随机转向或转圈采集功能；原始采样事实和同步待验证状态保留。
- [ ] 以现有 HTTP 集成边界覆盖带受控标注噪声的已知安装误差、随机顺序、混合 P/T/Z、多来源重分组、重复图片、分组超差、不可辨识、无需修正、过期冲突及重启恢复；使用独立椭球射线生成观测和真实求解器，不模拟候选结果。
- [ ] 维护相关接口、使用说明和模型版本约定；旧识别任务缺省无精修数据，原单任务生成、独立复核与只读 MCP 保持兼容。自动化检查只证明合成场景和状态契约，不声明修复了现场根因。
