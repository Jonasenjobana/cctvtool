# 03: 独立复核并应用精修候选

**What to build:** 标定人员可将有效联合精修候选作为独立复核来源，用另一组未参与计算的低倍、高倍和不同姿态截图评价固定参数；复核结果供人工判断，用户随后可手动将合格且未过期的候选应用到摄像头。全过程验证候选的完整输入版本，应用仅保存四项安装修正。

**Parent:** [基础倍率与随机高倍率截图联合精修安装参数](../../horizon-vertical-drift/issues/05-high-zoom-refinement.md)

**Blocked by:** 02：联合基础与多批高倍截图生成精修候选。需要其已保存的候选、结果编号和全部来源清单。

**Status:** resolved

- [x] 独立复核页面可区分并选择普通单任务结果和精修候选，明确展示候选来源、四项参数及有效状态；旧流程仍可使用。
- [x] 精修复核冻结候选参数和来源版本，按每张验证图自己的 P/T/FOV 与尺寸计算误差，不重新拟合、不修改参数或候选状态。
- [x] 图片独立性检查覆盖基础组与所有高倍精修实际参与图的并集；经其他识别任务重复引用的同一截图同样拒绝。未参与计算的真实重复拍摄图片允许作为验证观测。
- [x] 返回并展示逐图像素 RMS、角度 RMS、有符号垂直偏差、实际 P/T/Z、尺寸和失败图片；每张有效验证图的 RMS 均不超过 5 原图像素才通过，无有效观测不宣称通过。
- [x] 任何参与来源标注或忽略状态变化、基础结果更新、参与图删除、固定安装条件变化及旧结果编号，均使旧候选不能继续作为有效复核或应用来源；错误和冲突对用户可见。
- [x] 用户手动应用服务端保存的合格候选，不接受客户端提供的替代角度。应用同时校验候选编号、全部来源版本、生成时设备配置版本和现有设备控制占用条件。
- [x] 在同一事务中只保存四项安装修正及精修应用状态，返回新设备配置并同步当前页面预览；中途冲突不产生部分写入，重复应用和旧编号被拒绝。
- [x] 计算、独立复核和参数应用不触发设备运动，不修改原始 PTZ、原图、拍摄时配置副本、基础结果或其他来源标注；应用后的历史截图继续按拍摄事实回看。
- [x] 在 HTTP 集成测试中用真实生成的多来源候选验证完整的参与图排除、未参与样本固定参数复核、单图超差、版本失效、原子应用、重复请求和不相关数据保留，不通过模拟候选绕过来源契约。
- [x] 对普通单任务生成、原独立复核、旧任务和只读 MCP 执行必要回归，并更新用户操作与接口说明。前端按项目要求检查，浏览器、设备动作、机械重复性和现场高倍精度另行人工验收。
