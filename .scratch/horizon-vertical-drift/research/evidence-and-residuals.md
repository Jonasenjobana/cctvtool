# 海天线垂直偏差：现有证据与最小测量方案

核对日期：2026-11-13（UTC+8）。范围：当前工作区源码、`data/cctv.sqlite` 的只读聚合和一手标定资料。使用项目要求的 Node 22.22.3，以 `new DatabaseSync('data/cctv.sqlite', { readOnly: true })` 读取；查询在只读连接的读事务内完成，未调用会初始化或迁移数据的服务入口。未读取原图、操作设备、修改生产代码、运行测试、构建或浏览器调试。数据库统计的日期按记录 `createdAt` 的 UTC 日期截取。

## 结论与证据边界

- **用户已确认的现象**：8 倍时海天线的上下位置与倾斜程度均看起来和 Cesium 理论海天线重合；放大后主要上下错位，斜率接近。放大期间同时调整过 P 或 T，因此倍率和姿态是混杂变量，不能优先判成变倍漂移。
- **数据库已确认**：存在一对旧的、P/T 读数严格相等的 8 → 14.7 倍记录，但原图尺寸不同，画面与姿态同步均未验证；不存在恢复相同 P/T 的“8 → 高倍 → 8”闭环。它是可供后续回算的旧配对，不是本次用户现象的已确认复现。
- **本轮建议**：先冻结安装参数、P/T、媒体模式与观察位置，测量“8 → 一个高倍率 → 8”；再独立比较固定倍率下改 P、改 T 的情况。先建立有符号残差与重复性基线，再决定最小修正；本轮没有诊断出根因或完成修复。

| --- | --- | --- |
| 同 P/T、不同 Z | 仅 1 对：2026-11-12 的 8 → 14.7，间隔约 209 秒 | 两张均有未忽略的人工两点标注，安装副本相同，均未使用草稿；8 倍为 1920×1080，高倍为 960×540，同步均未验证。可后续用统一参考模型回算，不能把两次独立拟合的结果当成同一参考下的误差 |

## 当前模型给出的可检验约束

前端和拟合共用[固定安装与 P/T 旋转链](../../../shared/camera-rotation.ts#L4)。该链没有 Zoom 输入；[相机姿态](../../../src/app/camera-math.ts#L22)由安装参数及 P/T 决定，HFOV/VFOV 分别控制画面的横纵射线展开。[视频截面](../../../src/app/camera-math.ts#L68)完整映射两个 FOV，当前 UV 缩放为 1；模型采用中心主点，未提供按倍率的主点、光轴或光心位移输入，见[参数约定](../../../README.md#L191)。这是源码事实，不能据此断言真实镜头也满足这些假设。

必须统一比较模式：[实时场景使用当前草稿，历史场景使用截图保存的安装参数及 PTZ](../../../src/app/app.component.ts#L117)。实时 PTZ 采用[独立轮询](../../../src/app/app.component.ts#L206)，视频新帧通过[帧回调](../../../src/app/video-frame-loop.ts#L1)触发绘制，现有链路未提供二者严格同步的证据。因此“媒体与姿态状态不同步”仍是待测候选，不是已确认故障。

一个关键判据是：**若同 P/T、固定中心主点、同步且无裁剪的理想模型下，8 倍海天线在中心列恰好经过原图中心，则只改变 FOV 不会改变中心射线，也不应使这条中心射线离开海天线。** 完整原图中已有的非零角误差可以被高倍放大，但正确的纯 FOV 变化本身不会凭空生成该角误差。此判据须由原图量测确认，不能用“看起来重合”替代零残差。

## 统一测量口径

使用原图坐标，左上角为原点，纵坐标向下；沿用项目 `x=u/W`、`y=v/H` 的归一化约定，见[标注接口](../../../docs/API.md#L246)。对同一横坐标 `u` 定义：

```text
r_px(u) = v_实测(u) - v_理论(u)       正值：实拍海天线更靠下
r_01(u) = r_px(u) / H                图高归一化残差
fx = W / (2 tan(HFOV/2))
fy = H / (2 tan(VFOV/2))
```

焦距的单位为像素，主点和焦距属于不同内参；原图整体缩放时，这些像素内参也必须缩放。[OpenCV 官方针孔模型](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)给出相应定义；上面的 FOV 公式采用本工具的中心主点假设，与[样本准备](../../../server/tilt-calibration.mjs#L67)一致。

中心列 `u=cx=W/2` 可定义向下为正的垂直视角差：

```text
r_角 = atan((v_实测-cy)/fy) - atan((v_理论-cy)/fy),  cy=H/2
```

角度比较时换为度。接近原图中心且偏差很小时，`r_角 ≈ r_px/fy`（弧度）。其他列如需严格射线角差，应使用完整射线或项目的 WGS84 切线条件；不要把 `r_px×VFOV/H` 当作全图精确公式，也不要把这里的有符号中心列差与已有无符号模型 RMS 混用。这些是基于上述针孔方程提出的测量定义与推导，并非新增生产行为。[OpenCV 投影与归一化坐标定义](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)是推导依据。

每张至少记录中心列残差，并在共同可见且确有标注的左右位置记录残差；上下平移和倾斜分别观察。倾斜差可用原图像素下两条线的 `atan(Δv/Δu)` 之差表达。不能将标注区外的直线外推当成独立量测，也不直接测网页截图的 CSS 像素。

现有唯一严格配对说明了分辨率的影响：按接口 VFOV，8 倍原图的 `fy≈13805 px`，14.7 倍为 `fy≈12474 px`。对同一小角误差，高倍的**原图像素**量级约为前者的 0.904，而**图高归一化**量级约为 1.807。它们来自实际图高与 VFOV，不能拿 `14.7/8` 当焦距比。此例仅说明比较口径，未计算这两张图的实际偏差；接口 FOV 是否准确仍待验证。

## 单条海天线的可辨识性限制

下面是窄视场、局部直线、固定像素比例下的一阶分析，不是把 WGS84 海天线替换为无限平面。取中心列向下的海天线角为 `β`，针孔模型给出：

```text
v_h = cy + fy tan β
δv_h ≈ δcy + tan β·δfy + fy·sec²β·δβ
```

这项推导说明同一行位移可以由主点纵向变化、FOV／焦距误差、T 零偏或光轴／安装姿态变化的组合解释；倾斜近似相同只约束了线的方向，未分离上述高度项。`β=0` 时，单独焦距误差的一阶高度影响为零，与中心射线判据一致。[OpenCV 的内外参方程](https://docs.opencv.org/4.13.0/d9/d0c/group__calib3d.html)支持这一推导，不能据此反推本设备已发生某一种变化。

在当前每图两点直线表达下，一条线只有位置和方向两个独立自由度；同一线上增加点主要改善精度，不会自动得到互相独立的主点、焦距、俯仰及其随倍率变化。即便多 P 样本能在**固定内参**假设下通过现有四参数条件数检查，也不证明再增加按倍率主点和角度参数后仍可辨识。当前高度与默认朝向是固定输入，不是海天线验收结果，见[拟合约束与警告](../../../server/tilt-calibration.mjs#L318)。

一手资料给出的可选补充约束是：Collins 与 Tsin 的户外主动相机标定分别利用旋转／变倍产生的光流估计内参，再利用测量过的地标估计外参，见[作者的研究说明](https://www.cs.cmu.edu/~rcollins/calibration.html)；Zhang 的方法使用不同姿态的已知平面图案及重投影优化，见[原论文](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/tr98-71.pdf)。这些说明可用二维特征或已知几何增加约束，不是要求当前立即实现完整光学校准，也不是本设备的最低采样数量保证。

## 候选原因及可证伪预测

下表是后续测量应区分的候选，当前不作概率排序。

| 候选 | 受控情况下的预测 | 能反驳其单独解释的观测 |
| --- | --- | --- |
| 固定小角误差在高倍更显眼 | 同 P/T 时有符号角残差近似不变，像素差随实际 `fy` 缩放 | 统一状态下角残差随 Z 稳定改变且超过重复性误差；若中心射线在 8 倍确为零，纯倍率放大也应仍为零 |
| 安装旋转或 T 模型留下随姿态变化的残差 | 固定 Z 时，改变 P 或 T 后残差随该姿态重复出现；多 Z 换成角度口径后可检查共同趋势 | 固定 P/T 的变倍闭环已经稳定出现额外角残差，则“仅因这次改 P/T”不足以解释 |
| FOV 比例不准 | 在其他条件固定的局部模型下，误差随海天线离主点的距离变化；位于主点时纯比例项为零 | 中心射线固定却出现中心列偏移，不能只用 FOV 比例解释；仍需排除共同存在的姿态或主点误差 |
| 随倍率变化的中心视线或主点／裁剪 | 相同 P/T 下，不同 Z 有可重复的角偏差，返回 8 倍可恢复原基线；斜率可能近似不变 | 等待稳定并统一媒体和参数版本后该现象不再存在；即使预测成立，海天线也不能唯一分开主点与光轴变化 |
| 画面、PTZ、FOV 或参数版本未对齐 | 偏差与运动后等待、回读更新、媒体模式或参数版本相关；稳定后收敛或切换统一输入后消失 | 经重复静止采样、时间与图像内容复核后仍存在同一残差，可反驳“只是运动瞬态”的解释，但不能因此证明所有同步环节均正确 |

这些预测来自当前输入边界及前述针孔推导；不是本轮设备实验结果。海天线误标、遮挡、岸线混淆等仍须先通过原图复核排除，已有低 RMS 也不能代替这一检查，见[现有拟合警告](../../../server/tilt-calibration.mjs#L361)。

## 后续最小受控对照与修正边界

以下仅为后续由现场执行者开展的方案，本轮没有控制设备或采集新样本。

1. **冻结参考状态**：选定一个通道、一份明确的安装参数版本和同一媒体／预览模式；保持观察视点一致，按[现有对照要求](../../../README.md#L159)使用摄像头位置的最佳／跟随观察。新截图尽量使用相同尺寸和图像设置；尺寸变化则必须使用实际 W/H 重新换算。标注须针对原图，不能通过拖 T 将每个倍率重新调到看起来重合。历史与实时之间切换时，先核对其参数来源。
2. **先做变倍闭环**：从已对齐的 8 倍开始，保持 P/T，依次采集“8 → 一个出现问题的高倍率 → 8”。每个稳定状态连续取得至少两张，以估计标注和静止重复性；若首次出现差异，再重复两轮检查返回性。逐状态保留前后真实 P/T/Z/FOV、请求时间及画面时间线索，不能把 `poseChanged=false` 记成已同步。若 P/T 没有恢复到相同读数，列为有姿态变化的样本，不混入严格对照。
3. **再单独改姿态**：固定 Z 和 T，做 P 基线 → 另一 P → 返回基线；若仍需区分 FOV 比例与常量高度项，再固定 P/Z 取得使海天线位于中心上下两侧的 T 对照，且保留可见海天线与设备允许范围。P、T 分开改变，不在一次比较中同时换 Z/P/T。仍不可分时才增加稳定二维地物特征或独立标定图案。
4. **先定误差目标再判断**：同时记录 `r_px/r_01/r_角` 与倾斜差，比较差异是否超过静止重复性及标注误差。用户的允许像素／角度误差尚未给出，本轮不虚构验收阈值。旧配对若用于回算，必须使用同一份明确的参考安装参数；不拿各自优化后的 RMS 当跨倍率误差。

修正选择服从证据：如果偏差只出现在状态未对齐时，优先处理对应状态来源或同步边界；如果固定角残差能跨倍率预测，则先复核既有安装／T 参数并以未参与拟合的姿态和高倍样本验证；只有固定 P/T 的闭环稳定显示额外倍率相关偏差，才进入光学自由度研究。即使到这一步，也应先通过额外特征区分 FOV、主点和角度项，选择一个有证据的最小自由度，避免同时加入可以互相抵消的多套补偿。本轮不添加任何按倍率参数，不应用已有拟合结果。

**仍待验证**：本次现象的量化复现、变倍与转向的独立贡献、原图真海天线标注、严格同步、接口 FOV 准确性、机械返回重复性，以及用户要求的最终容许误差。当前研究仅明确了现有证据缺口、残差口径及首轮最小对照。
