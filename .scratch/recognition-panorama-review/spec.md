# 识别全景与相邻端点复核交互规格

Status: resolved

## Problem Statement

自定义较小 P 间隔后，多张截图在合成全景里高度重叠。当前选图只裁剪其他标线，背景仍由多图融合，用户难以辨认正在标注哪一张原图；逐张检查时也缺少前后标注和统一海天线走势的对照。

## Solution

保留全景总览，并在聚焦编辑时将当前原图按相同投影不透明置顶。提供自动保存、保持缩放并定位的前后切图。在下方单图复核中显示相邻截图的只读端点和参考线；全景另可绘制一条直线或简单弧线，映射到单图作为独立参考，随任务保存。

## User Stories

1. 作为标注人员，我希望在全景总览查看全部截图和海天线，以便判断整体走势。
2. 作为标注人员，我希望选中截图后看清该图自己的画面，以便密集采样时准确调整标注。
3. 作为标注人员，我希望聚焦时仅编辑当前图的线和端点，以免误选重叠标注。
4. 作为标注人员，我希望随时切回全景总览，以便继续检查整体连贯性。
5. 作为标注人员，我希望使用上一张／下一张按采样顺序复核，以便不必点击密集线段。
6. 作为标注人员，我希望切图前自动保存，以免丢失当前调整。
7. 作为标注人员，我希望保存失败后保留草稿和当前图，以便修正后重试。
8. 作为标注人员，我希望切图保持缩放并将新图移到可见区，以便连续编辑。
9. 作为标注人员，我希望跨 0° 时仍按采样顺序切图，以免前后关系错乱。
10. 作为标注人员，我希望下方原图显示前后截图的端点和参考线，以便人工比较接续位置。
11. 作为标注人员，我希望相邻标注只作参照，以免修改当前图时意外改动邻图。
12. 作为标注人员，我希望区分上一张、下一张、模型结果及当前标注，以便清楚判断来源。
13. 作为标注人员，我希望忽略图和缺少标注的状态明确，以免把不可用参照当成有效标注。
14. 作为标注人员，我希望在合成全景中拉一条直线或水平线，以便统一观察海天线高度。
15. 作为标注人员，我希望使用简单弧线及弯曲控制点，以便对照略弯的海天线走势。
16. 作为标注人员，我希望调整参考线端点和覆盖范围，以便只覆盖需要复核的区域。
17. 作为标注人员，我希望全景参考线映射到当前单图，以便根据统一参照手工调整两个正式端点。
18. 作为标注人员，我希望映射保留实际曲线和可见片段，以免得到错误的直线或跨缺口连线。
19. 作为标注人员，我希望单独隐藏相邻参照或全景参考线，以便需要时看清原图。
20. 作为标注人员，我希望保存、撤销、删除及重画参考线，以便反复调整。
21. 作为标注人员，我希望刷新或重建全景后继续使用已保存的参考线，以免重复绘制。
22. 作为标注人员，我希望参考线按识别任务隔离，以免另一任务的辅助线混入。
23. 作为标注人员，我希望保存辅助参考线不改变正式标注或安装结果，以便保持现有复核与应用流程。
24. 作为标注人员，我希望保持原有拖端点、键盘微调和撤销，以便继续熟悉的编辑操作。
25. 作为标注人员，我希望切图加载失败时明确报错，以免把上一张画面误当成当前图。

## Implementation Decisions

- 全景总览显示融合背景和各图海天线；聚焦编辑将当前截图完整投影不透明置顶，外部保留全景背景，仅当前线和两个端点可编辑。
- 置顶层与标注复用同一全景计划及采样姿态，切图不改变全景范围。没有有效标线的现存截图仍能被聚焦查看。
- 前后切图按现存截图的采样顺序，首尾不循环，保留忽略图，跳过已删除图；切图自动保存，失败不切换，保持缩放并将当前图移到可见区域。
- 相邻参照仅显示在下方单图区域。取采样序列中紧邻的前后截图，按各自保存的安装参数及 PTZ/FOV 转换到当前原图；真实端点在画面内时显示，画面外仍保留可见参考线片段。无有效标注或无重叠时省略，忽略参照体现其状态。
- 全景一次绘制一条直线或二次弧线；直线两个端点，二次弧线按起点、控制点、终点排序。支持调整范围、拖动、显示／隐藏、保存、撤销、删除和重画。
- 绘线在合成全景总览进行，与逐图选图、标注拖动互斥，避免误触。映射到单图时保留实际曲线及可见片段，不直接变为正式两点标注，不自动吸附或联动邻图。
- 持久点包含展开方位 heading（弧度）与 elevation（射线 z/水平长度），独立于全景 PNG 尺寸。缩放、刷新及同任务全景重建不得使参考漂移。
- 独立 GET/PUT 全景参考线接口返回 guide 与独立 revision；PUT 校验版本，guide:null 删除。旧任务缺省 guide:null、revision:0。保存不改变识别任务的正式 revision、updatedAt、result、resultId 或应用状态。
- 单图正式标注仍为两个归一化点，保留模型原始结果、忽略状态、草稿、撤销及安装结果失效规则。参考线不进入拟合，不继承到新一轮识别任务。
- 异步置顶层隔离迟到结果并支持取消、清理；保存错误保留草稿；切任务和离页先完成待保存的复核修改。

## Testing Decisions

- 沿用讨论中记录并随本规格获准实施的公开几何函数及模拟 HTTP 接口，不新增组件测试。
- 几何测试从已知方向、独立合成图像及可观察结果验证投影、跨零、不同 T/FOV/Roll、邻图映射、弧线裁切和置顶画面颜色，不以内部实现复算预期。
- HTTP 测试验证任务隔离、保存／删除／重启、独立版本冲突、输入校验、旧任务兼容及正式标注和安装结果完全不变，沿用现有识别接口夹具。
- 页面交互按源码与规格逐项核对，执行类型／模板编译和生产构建；集成后运行完整回归。
- 不运行浏览器调试或真实云台动作。测试和构建不能替代实际交互、WebGL 或现场精度验收。

## Out of Scope

多条独立曲线、多段路径编辑器、自动生成或批量覆盖正式标注、跨图联动修改、重新识别或改变安装拟合算法、近景视差与镜头畸变修正。
