# 01: 在 Cesium 编辑并预览零位姿态

**What to build:** 标定人员打开摄像头后，可用三轴方位盘和表单调整同一组零位 Roll、Pitch、Yaw，在 Cesium 看相机模型随设备 P/T 改变姿态，并保存、重载或放弃编辑。通过保存入口保留可供后续拟合的新版零位参数。

**Parent:** [Cesium 相机零位姿态标定规格](../spec.md)

**Blocked by:** 无，可立即开始。

**Status:** ready-for-agent

- [ ] 已有摄像头可以打开零位姿态编辑区。使用旧模型的零位旋转初始化 Roll、Pitch，以已保存 P 朝向初始化 Yaw，带入保存的 T 补偿。
- [ ] 方位盘与数值表单双向同步三个以度表示的零位角，零位四元数以 $(x,y,z,w)$ 显示。标示当地东、北、天和相机光轴，用户可从模型外侧及镜头视角查看同一姿态。
- [ ] 设备 P、T 为零、Z 为一且额外光轴旋转为零时，模型与表单的零位姿态一致。其他读数按补偿后的 P/T 相对转动显示，视锥使用实际视场角。
- [ ] 实时回读和 Cesium 观察视角的变化不会覆盖姿态草稿。回读缺失时明确显示零位参考，预览操作只更新软件姿态。
- [ ] Yaw 手调只应用一次基准和修正。单独手调 T 补偿时按原机械校正方向更新零位姿态和三角读数。
- [ ] 通过既有保存流程保存并重新载入新版参数。放弃编辑恢复已保存值，保存失败保留草稿。在新版应用前，原生效标定供日常显示与定位。
- [ ] 以现有 HTTP 测试核对保存、重载及旧摄像头留存，以几何回归核对补偿、回零和四元数等价。三轴联动与 Cesium 观察按人工流程验收。
