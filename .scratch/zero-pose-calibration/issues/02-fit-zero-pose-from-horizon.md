# 02: 由海天线生成零位姿态候选

**What to build:** 标定人员可以从识别任务的正式海天线生成零位姿态候选，在相机预览中查看求得的 Roll、Pitch 和逐图误差，并了解样本范围和结果能否供后续使用。

**Parent:** [Cesium 相机零位姿态标定规格](../spec.md)

**Blocked by:** [在 Cesium 编辑并预览零位姿态](01-edit-and-preview-zero-pose.md)。

**Status:** implemented

- [x] 从同一摄像头的有效正式标注求解零位 Roll 和 Pitch。按每张原图的原始 P/T、视场角和尺寸计算理论海天线。
- [x] 求解冻结有效 Yaw、已保存 T 补偿及安装位置。候选使用新版零位姿态模型，独立光轴旋转取零。
- [x] 识别任务展示两个拟合值、冻结的方位和补偿、方向覆盖、参与图、排除原因、逐图残差和可靠性。可在参与原图上预览候选理论线，应用由操作者单独确认。
- [x] 保存模型版本、相机配置版本及所用正式标注、实际参与图的版本信息。样本缺失或约束不足时显示明确状态，已失效结果只保留诊断。
- [x] 既有正式标注、忽略状态和旧版识别结果继续可读。旧参数可以初始化草稿，生成候选期间保留原图及采样事实。
- [x] 以现有 HTTP 测试覆盖真实生成与预览入口、适用样本筛选、Yaw 和 T 补偿冻结、旧结果读取、版本失效、缺图与拟合不可靠反馈。
- [ ] 待人工验收。在识别页打开实际参与图，核对理论线预览、逐图误差展示及失效反馈。
