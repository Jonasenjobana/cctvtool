# 03: 用基础图和高倍图联合精修

**What to build:** 标定人员可以选用有效的基础零位姿态结果和已标注的高倍原图，生成同一版本的联合精修候选。可打开实际参与图片，在相同观测条件下查看精修前后的理论海天线和像素差。

**Parent:** [Cesium 相机零位姿态标定规格](../spec.md)

**Blocked by:** [由海天线生成零位姿态候选](02-fit-zero-pose-from-horizon.md)。

**Status:** done

- [x] 沿用已有基础来源与高倍来源选择流程。能说明来源无有效标定、无正式标注或缺少合格高倍观测时无法生成的具体原因。
- [x] 按每张图自己的 P/T、视场角和尺寸共同拟合零位 Roll 和 Pitch，冻结已有 Yaw 和 T 补偿。基础组与高倍组按现有等权口径贡献误差。
- [x] 基础结果和精修候选使用相同模型版本。精修记录冻结相机配置、基础结果、各来源正式标注版本及实际参与图片。来源变动使对应候选失效。
- [x] 参与图对照在同一张原图上展示精修前后理论海天线、实际采样条件和有符号垂直偏差，允许只读打开外部来源图片。
- [x] 保存精修候选后可继续查看基础结果和各自的标注。质量未达要求的候选明确给出诊断，原生效标定供继续使用。
- [x] 以现有 HTTP 集成测试覆盖基础与多来源高倍观测、重复图片排除、版本不匹配、前后同图对照和候选失效。

浏览器中的原图切换、真实设备与现场高倍精度由操作人员验收。
