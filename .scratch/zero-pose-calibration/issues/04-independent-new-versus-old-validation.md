# 04: 用独立高倍原图复核新旧模型

**What to build:** 标定人员可以选择未参与拟合的原图，以同一批观测复核现有标定和新版普通候选，逐张查看换方位后的误差，用实测结果判断零位姿态模型能否覆盖高倍画面。

**Parent:** [Cesium 相机零位姿态标定规格](../spec.md)

**Blocked by:** [由海天线生成零位姿态候选](02-fit-zero-pose-from-horizon.md)。

**Status:** implemented

- [x] 显式提交复核，对照当前生效标定和一个有效零位候选。两套计算使用同一组独立观测、其真实 P/T、视场角、原图尺寸与正式标注。
- [x] 独立性检查排除生效标定和零位候选实际参与拟合的原图。来源、标注、原图或相机配置失效时明确告知原因。
- [x] 逐图展示原图左、中、右可比较位置的有符号垂直偏差、海天线方向差、像素 RMS 和实际 P/T/Z。标出无可比较观测、逐图超差及覆盖不足。
- [x] 复核计算冻结输入参数。高倍通过至少需要两个两种模型均可比较的实际 P 方位，同方位复拍继续作为独立样本。验收门槛按重复拍摄和重复标注得到的现场误差制定。
- [x] 独立复核保留来源及样本身份，结果可供应用时核对。证据不足和逐图未通过时有清楚状态，原标定仍可用于运行。
- [x] HTTP 测试覆盖固定参数测量、参与图限制、两种参数各自产生的误差、逐图超差、覆盖不足和版本过期。
- [ ] 待人工验收。逐图检查浏览器同图切换，并按真实复拍与重标确定门槛后完成独立高倍复核。
