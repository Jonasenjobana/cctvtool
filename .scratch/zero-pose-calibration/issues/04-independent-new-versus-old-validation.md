# 04: 用独立高倍原图复核新旧模型

**What to build:** 标定人员可以选择未参与拟合的原图，以同一批观测复核现有标定和新版普通候选，逐张查看换方位后的误差，用实测结果判断零位姿态模型能否覆盖高倍画面。

**Parent:** [Cesium 相机零位姿态标定规格](../spec.md)

**Blocked by:** [由海天线生成零位姿态候选](02-fit-zero-pose-from-horizon.md)。

**Status:** ready-for-agent

- [ ] 可固定现有标定与一个有效新版普通候选做对照。两套计算使用同一组独立观测、其真实 P/T、视场角、原图尺寸与正式标注。
- [ ] 独立性检查依据来源实际参与图片，拒绝把已参与该来源拟合的图再次作为复核图。来源、标注或相机配置失效时明确告知原因。
- [ ] 逐图展示原图左、中、右可比较位置的有符号垂直偏差、海天线方向差、像素 RMS 和实际 P/T/Z。标出无可比较观测、逐图超差及覆盖不足。
- [ ] 复核计算冻结输入参数。可根据独立原图结果查看同一项目的旧版与新版低倍、高倍及关键 P/T 方位表现，并按重复拍摄和重复标注得到的现场误差制定验收门槛。
- [ ] 独立复核保留来源及样本身份，结果可供应用时核对。证据不足和逐图未通过时有清楚状态，原标定仍可用于运行。
- [ ] HTTP 测试覆盖固定参数测量、参与图限制、两种参数各自产生的误差、逐图超差以及版本过期。真实重复拍摄、重标与高倍精度按独立原图人工验收。
