# 05: 复核后手动切换生效模型

**What to build:** 标定人员确认普通或精修候选通过独立复核后，可以手动应用新版零位标定。生效后，实时地图和目标定位共享新版姿态关系，历史截图及旧结果仍可按原版模型回看。

**Parent:** [Cesium 相机零位姿态标定规格](../spec.md)

**Blocked by:** [用基础图和高倍图联合精修](03-joint-refinement-across-zooms.md) 和 [用独立高倍原图复核新旧模型](04-independent-new-versus-old-validation.md)。

**Status:** implemented

- [x] 既有应用入口能处理新版普通和精修候选。界面显示模型版本、候选来源、独立复核状态及可应用条件，由操作者显式确认切换。
- [x] 应用读取服务端保存的候选，并核对候选、相机配置、基础和高倍来源、参与图及独立复核的版本。请求过期、复核未通过或数据变动时给出明确提示。
- [x] 在一次写事务中更新生效参数、模型版本、标定来源及参与原图 ID。重复请求或失败时保留一致的既有配置。当前页面从返回的生效数据更新预览，并保留零位候选以外未保存的四参数编辑。
- [x] 生效后，实时视频投影、3D 姿态和世界目标至原始 P/T 的反算共用新版旋转关系。设备控制入口继续接收原始 P/T。
- [x] 旧设备能继续使用已有标定，历史截图仍按拍摄时的模型和参数复核。已应用的普通和精修零位候选可查看冻结的原图与理论线。已知生效来源在原任务改标或重算后仍保留，更换设备通道会清除前一设备的生效零位与来源。
- [x] 用 HTTP 集成测试覆盖新版普通、精修候选的复核与应用、过期候选和跨版本错用拒绝、保存失败及重复提交，并核对旧版合法结果的原有应用路径。几何回归覆盖设备零位、跨零 P 和多组 T 的正反算一致性。
- [ ] 待人工验收。核对浏览器中确认、切换和历史回看，使用真实设备检查投影与目标 P/T，并按独立高倍原图验收现场精度。
