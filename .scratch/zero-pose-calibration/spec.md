# Cesium 相机零位姿态标定规格

Status: implemented

## Problem Statement

操作者需要在地图中看清真实摄像头的朝向，并直观调整姿态。现有安装表单需要分别理解 P 轴前后倾、左右倾和末端画面滚转。调参时缺少一个同时展示相机模型、三个姿态角与变动结果的入口。海天线拟合也以这些安装修正项为结果，操作者很难把结果直接对应到正在观察的相机姿态。

## Solution

Cesium 场景用 3D 模型根据设备实时读数展示当前姿态。三轴方位盘和表单共同编辑一组零位 Yaw、Pitch、Roll，同时显示该姿态的单位四元数。零位以设备回读 P、T 为零、Z 为一时的镜头旋转定义。

海天线拟合直接求解零位 Roll 和 Pitch，沿用已保存的 Yaw 和设备相对转动关系。旧 T 偏移体现在零位镜头的俯仰中。候选可按参与图查看理论海天线和误差，由用户确认后应用。

## User Stories

1. 作为标定人员，我希望在 Cesium 中看到所选摄像头的 3D 模型，以便观察实际镜头朝向。
2. 作为标定人员，我希望同时看到镜头光轴和当地东、北、天方向，以便判读姿态。
3. 作为标定人员，我希望从模型外侧和镜头视角观察，以便核对安装方向及画面对齐。
4. 作为标定人员，我希望用方位盘调整零位 Yaw，以便直观校准水平朝向。
5. 作为标定人员，我希望用方位盘调整零位 Pitch，以便直观校准抬头和下俯。
6. 作为标定人员，我希望用方位盘调整零位 Roll，以便校准零位画面滚转。
7. 作为标定人员，我希望用数字输入精确调整同一组三个角，以便复现细小的标定改动。
8. 作为标定人员，我希望方位盘和数字框双向同步，以便两种操作得到同一个姿态草稿。
9. 作为标定人员，我希望角度标为度，并能读出正负方向，以便确认调整方向。
10. 作为标定人员，我希望看到零位姿态的四元数，以便对照三维系统的旋转数据。
11. 作为标定人员，我希望能区分零位角和当前设备回读，以便知道每个数字的参照。
12. 作为标定人员，我希望回到设备零位时模型姿态与表单一致，以便验证坐标和符号。
13. 作为标定人员，我希望设备转动后模型跟随 P/T，以便预览同一套标定在不同方位的效果。
14. 作为标定人员，我希望设备读数刷新时保留正在编辑的零位草稿，以便稳定微调。
15. 作为标定人员，我希望回读暂时缺失时仍能查看零位参考，以便继续调整零位姿态。
16. 作为标定人员，我希望转动 Cesium 观察视角时保留草稿，以便换角度观察同一个模型。
17. 作为标定人员，我希望通过显式保存应用手动编辑，以便在保存前比较调整结果。
18. 作为标定人员，我希望放弃草稿后恢复已保存姿态，以便撤销本次尝试。
19. 作为标定人员，我希望保存失败时保留当前草稿，以便修正再保存。
20. 作为标定人员，我希望从已有标定得到零位 Yaw，以便沿用已校准的朝向。
21. 作为标定人员，我希望手调 Yaw 并查看模型响应，以便用已知方位的地物对准朝向。
22. 作为标定人员，我希望通过 Pitch 调整回零时的俯仰，以便只用三轴表单校对零位。
23. 作为标定人员，我希望自动求解直接输出零位 Roll 和 Pitch，以便把候选直接用于三轴表单。
24. 作为标定人员，我希望自动求解沿用已保存的 Yaw，以便保留已核对的方位基准。
25. 作为标注人员，我希望拟合使用截图自己的 P/T、视场角和原图尺寸，以便按实际像素评价。
26. 作为标注人员，我希望继续使用已有正式海天线和忽略状态，以便复用已复核的标注。
27. 作为标定人员，我希望知道哪些图被排除和为什么，以便补齐可用观测。
28. 作为标定人员，我希望看到每张图的拟合残差和方位覆盖，以便发现局部偏差和集中采样。
29. 作为标定人员，我希望查看求解可靠性，以便辨认支撑不足的角度结果。
30. 作为标定人员，我希望在参与原图上叠加候选的理论海天线，以便对照正式标注。

36. 作为标定人员，我希望打开旧截图时看到拍摄时的几何关系，以便按原条件复核历史记录。
37. 作为维护人员，我希望已有摄像头有可用的零位姿态草稿初值，以便逐台试用新模型。
38. 作为操作人员，我希望地图预览和目标定位使用同一个姿态模型，以便视觉朝向与 P/T 反算一致。

## Implementation Decisions

- 零位姿态以相机所在地的 ENU 为参考。相机局部 X 向右、Y 向前、Z 向上。Yaw 从真北顺时针计角，Pitch 向上为正，Roll 绕相机前轴按右手规则计角。零位旋转采用 $R_0=R_z(-\mathrm{Yaw})R_x(\mathrm{Pitch})R_y(\mathrm{Roll})$。
- 设备返回原始 P、T，T 正值表示下俯。设机械 T 零点为 $\delta$，末端画面滚转为 $\rho$，局部转动为 $D(P,T)=R_z(-P)R_x(\delta-T)R_y(\rho)$。当前姿态为 $R_{\mathrm{current}}=R_0D(0,0)^\mathsf{T}D(P,T)$。设备回零时相对转动抵消，镜头的俯仰直接取零位 Pitch。
- 界面只编辑 Yaw、Pitch、Roll。旧安装姿态从设备回零时的旋转分解为三个角，并保留 $\delta$ 与 $\rho$ 用于恢复机械相对转动。缺少的历史修正按 0 处理。
- Z 为一是零位参考的光学条件。截图和实时视锥的投影使用对应的实测视场角和画面尺寸。
- 三轴操作盘和表单共享零位草稿。打开编辑器时沿用地图当前观察方式和镜头姿态，调整角度或主动选择后预览草稿。3D 相机模型、光轴和视锥用所选姿态来源和原始 P/T 生成，经相机位置的 ENU 变换放入 Cesium 世界坐标。四元数以 $(x,y,z,w)$ 顺序显示零位姿态，由同一组三角对应的旋转转换。观察视角与姿态草稿独立，设备回读缺失时标出当前显示的是零位参考。
- 校准草稿通过既有保存入口确认。操作三轴盘、改变观察视角和预览拟合候选属于软件侧姿态编辑。实际云台仍由现有控制入口操作。有效配置更新后，从同一姿态关系计算视频投影和目标 P/T 反算。
- 普通拟合以零位 Roll、Pitch 为优化变量，沿用有效 Yaw、相对转动关系和安装位置。对每张有效截图代入其原始 P/T 和视场角，使用原图海天线残差与正式标注。未启用零位模型的旧标定任务在机械修正为零且普通拟合超差时，可沿用同一安装条件下曾应用的历史标定配置重算。输出三轴姿态角、配置版本、参与图、排除原因、几何可靠性和逐图误差。
- 界面按参与图的正式两端点、保存的原始 P/T 和视场角计算理论海天线。5 原图像素是 RMS 提示值。有效且当前的候选由用户确认应用。
- 应用入口核对正式标注版本、候选编号、相机配置及参与原图，检查设备占用，并在同一事务中保存候选状态和生效配置。历史截图以拍摄时冻结的配置转换为等价零位姿态。

## Testing Decisions

- 用现有标定 HTTP 集成测试作为主入口。验证手调保存生效、直接拟合零位 Roll 和 Pitch、沿用 Yaw、候选预览、手动应用和旧结果失效。
- HTTP 测试使用已有的截图元数据、正式标注和冻结版本数据。覆盖旧数据读取、缺少或无效样本、超差候选预览、应用失败的状态一致性。断言可观察的结果、误差符号、配置和版本行为。
- 复用现有相机几何回归。核对设备零位与表单一致，旧姿态在跨零 P、不同 T 和垂直光轴时转换等价，以及 ENU 到地固坐标转换、四元数与矩阵等价、P/T 正反算一致。
- Cesium 3D 模型、三轴盘与表单双向同步按操作者流程人工验收。实际设备重复拍摄、固有回读误差和高倍对齐在独立原图上人工复核。比较左右及中点的垂直残差、斜率和每张图的像素 RMS。

## Out of Scope

- 单凭海天线自动确定绝对 Yaw，或新增地标方向拟合。
- 新增设备 PTZ 指令、自动扫描或自动应用校准结果。
- 改写既有截图、正式标注或原始设备采样记录。
- 独立的变倍主点漂移、镜头畸变等光学模型扩展。

## Further Notes

T 补偿手调采用保持原机械校正作用的约定。补偿由 $\delta$ 改为 $\delta'$ 时，更新零位旋转为 $R_0R_x(\delta'-\delta)$，并从该旋转更新表单。设备零位相对旋转仍为单位矩阵。

新增姿态模型的适用性由独立原图验收决定。若随 P/T 或倍率的残差超过复拍与重标水平，先复核姿态模型与光学条件，再决定是否恢复独立光轴旋转或补充观测。
