# Cesium 相机零位姿态标定规格

Status: open
Labels: ready-for-agent

## Problem Statement

操作者需要在地图中看清真实摄像头的朝向，并直观调整姿态。现有安装表单需要分别理解 P 轴前后倾、左右倾和末端画面滚转。调参时缺少一个同时展示相机模型、三个姿态角与变动结果的入口。海天线拟合也以这些安装修正项为结果，操作者很难把结果直接对应到正在观察的相机姿态。

## Solution

在现有 Cesium 场景加入相机姿态编辑区。3D 模型根据设备实时读数展示当前姿态。三轴方位盘和表单共同编辑一组零位 Roll、Pitch、Yaw，同时显示该姿态的单位四元数。零位以设备回读 P、T 为零、Z 为一、额外绕光轴旋转为零定义。

新海天线模型直接求解零位 Roll 和 Pitch。Yaw 沿用已有 P 朝向并由操作者手调，T 补偿继续使用已保存值。实时姿态由零位旋转和设备相对 P/T 转动计算。用同一批原图对照现有模型和新候选，并以独立高倍复核决定何时启用新版。

## User Stories

1. 作为标定人员，我希望在 Cesium 中看到所选摄像头的 3D 模型，以便观察实际镜头朝向。
2. 作为标定人员，我希望同时看到镜头光轴和当地东、北、天方向，以便判读姿态。
3. 作为标定人员，我希望从模型外侧和镜头视角观察，以便核对安装方向及画面对齐。
4. 作为标定人员，我希望用方位盘调整零位 Yaw，以便直观校准水平朝向。
5. 作为标定人员，我希望用方位盘调整零位 Pitch，以便直观校准抬头和下俯。
6. 作为标定人员，我希望用方位盘调整零位 Roll，以便校准零位画面滚转。
7. 作为标定人员，我希望用数字输入精确调整同一组三个角，以便复现细小的标定改动。
8. 作为标定人员，我希望方位盘和数字框双向同步，以便两种操作得到同一个姿态草稿。
9. 作为标定人员，我希望角度标为度，并能读出正负方向，以便确认调整方向。
10. 作为标定人员，我希望看到零位姿态的四元数，以便对照三维系统的旋转数据。
11. 作为标定人员，我希望能区分零位角和当前设备回读，以便知道每个数字的参照。
12. 作为标定人员，我希望回到设备零位时模型姿态与表单一致，以便验证坐标和符号。
13. 作为标定人员，我希望设备转动后模型跟随 P/T，以便预览同一套标定在不同方位的效果。
14. 作为标定人员，我希望设备读数刷新时保留正在编辑的零位草稿，以便稳定微调。
15. 作为标定人员，我希望回读暂时缺失时仍能查看零位参考，以便继续调整零位姿态。
16. 作为标定人员，我希望转动 Cesium 观察视角时保留草稿，以便换角度观察同一个模型。
17. 作为标定人员，我希望通过显式保存应用手动编辑，以便在保存前比较调整结果。
18. 作为标定人员，我希望放弃草稿后恢复已保存姿态，以便撤销本次尝试。
19. 作为标定人员，我希望保存失败时保留当前草稿，以便修正再保存。
20. 作为标定人员，我希望沿用已有 P 朝向作为 Yaw 基准，以便减少重复的现场方位标定。
21. 作为标定人员，我希望手调 Yaw 并查看模型响应，以便用已知方位的地物对准朝向。
22. 作为标定人员，我希望继续能手动调整 T 零位补偿，以便校正设备俯仰读数偏移。
23. 作为标定人员，我希望自动求解直接输出零位 Roll 和 Pitch，以便把候选直接用于三轴表单。
24. 作为标定人员，我希望自动求解使用已保存的 Yaw 和 T 补偿，以便保留已核对的方位基准。
25. 作为标注人员，我希望拟合使用截图自己的 P/T、视场角和原图尺寸，以便按实际像素评价。
26. 作为标注人员，我希望继续使用已有正式海天线和忽略状态，以便复用已复核的标注。
27. 作为标定人员，我希望知道哪些图被排除和为什么，以便补齐可用观测。
28. 作为标定人员，我希望看到每张图的拟合残差和方位覆盖，以便发现局部偏差和集中采样。
29. 作为标定人员，我希望查看求解可靠性，以便辨认支撑不足的角度结果。
30. 作为标定人员，我希望用同一批图对照旧模型和新候选，以便看清改动对精度的影响。
31. 作为标定人员，我希望用未参与拟合的高倍原图检查换方位后的偏差，以便判断能否省去额外光轴滚转。
32. 作为标定人员，我希望分别看到海天线高度偏差和方向差，以便区分俯仰与画面滚转误差。
33. 作为标定人员，我希望按原图逐张检查高倍结果，以便找到平均值掩盖的超差图。
34. 作为标定人员，我希望在新版候选未通过复核时仍可使用现有标定，以便保持设备可用。
35. 作为标定人员，我希望在应用候选前核对所用参数与来源版本，以便避免套用旧结果。
36. 作为标定人员，我希望打开旧截图时看到拍摄时的几何关系，以便按原条件复核历史记录。
37. 作为维护人员，我希望已有摄像头有可用的零位姿态草稿初值，以便逐台试用新模型。
38. 作为操作人员，我希望地图预览和目标定位使用同一个姿态模型，以便视觉朝向与 P/T 反算一致。

## Implementation Decisions

- 零位姿态以相机所在地的 ENU 为参考。相机局部 X 向右、Y 向前、Z 向上。Yaw 从真北顺时针计角，Pitch 向上为正，Roll 绕相机前轴按右手规则计角。零位旋转采用 $R_0=R_z(-\mathrm{Yaw})R_x(\mathrm{Pitch})R_y(\mathrm{Roll})$。
- 设备返回原始 P、T，T 正值表示下俯。设已保存 T 零位补偿为 $\delta$，局部转动为 $D(P,T)=R_z(-P)R_x(\delta-T)$。当前姿态为 $R_{\mathrm{current}}=R_0D(0,0)^\mathsf{T}D(P,T)$，以设备回读的零位为相对转动的起点。
- P 朝向作为零位 Yaw 的已知基准。界面展示可手调的绝对零位 Yaw，保存时保留该基准及调整后的有效朝向关系。姿态链应用这项方位信息一次。T 补偿由已有配置提供，调整时按机械俯仰零位更新零位旋转，并同步三个角。
- Z 为一是零位参考的光学条件。截图和实时视锥的投影使用对应的实测视场角和画面尺寸。独立光轴旋转在新候选中取零，零位 Roll 参与姿态求解。
- 三轴操作盘和表单共享零位草稿。3D 相机模型、光轴和视锥由草稿加原始 P/T 生成，经相机位置的 ENU 变换放入 Cesium 世界坐标。四元数以 $(x,y,z,w)$ 顺序显示零位姿态，由同一组三角对应的旋转转换。观察视角与姿态草稿独立，设备回读缺失时标出当前显示的是零位参考。
- 校准草稿通过既有保存入口确认。操作三轴盘、改变观察视角和预览拟合候选属于软件侧姿态编辑。实际云台仍由现有控制入口操作。有效配置更新后，从同一姿态关系计算视频投影和目标 P/T 反算。
- 新求解器以零位 Roll、Pitch 为优化变量，冻结有效 Yaw、保存的 T 补偿和安装位置。对每张有效截图代入其原始 P/T 和视场角，沿用原图海天线残差、正式标注、忽略和样本有效性语义。输出两项姿态角、固定参数版本、参与图、排除原因、几何可靠性和逐图误差。
- 普通拟合、联合精修及独立复核遵循同一个生效模型及旋转顺序。新旧模型结果带各自版本。复核使用冻结参数和独立原图。应用入口核对候选、样本和相机配置版本，并在用户确认后保存整份结果。
- 旧摄像头可以由旧模型在设备零位的姿态初始化 Roll、Pitch 草稿，Yaw 用已保存 P 朝向初始化。旧标定和拍摄时的样本快照可按旧版本回看。新版本以零位三角和补偿为生效输入，旧 P 轴倾角用于历史解释和初始化。
- 采用同一现场样本条件比较新旧模型。验收以独立高倍原图的垂直偏差、方向差及逐图 RMS 为依据，门槛通过重复拍摄和重复标注先测定。新模型证据不足或在关键方位退化时，继续使用现有配置并保留新候选供复核。

## Testing Decisions

- 用现有标定 HTTP 集成测试作为主入口。验证相机保存与读取、直接拟合零位 Roll 和 Pitch、固定 Yaw/T 补偿、候选预览、独立复核、手动应用和旧结果失效。
- HTTP 测试使用已有的截图元数据、正式标注和冻结版本数据。覆盖旧数据读取、缺少或无效样本、拟合与验证分离、模型启用失败的状态一致性。断言可观察的结果、误差符号、配置和版本行为。
- 复用现有相机几何回归。核对设备零位与表单一致、含 T 补偿的相对旋转、手调 T 补偿与零位联动、跨零 P、不同 T、ENU 到地固坐标转换、四元数与矩阵等价以及 P/T 正反算一致性。
- Cesium 3D 模型、三轴盘与表单双向同步按操作者流程人工验收。实际设备重复拍摄、固有回读误差和高倍对齐在独立原图上人工复核。比较左右及中点的垂直残差、斜率和每张图的像素 RMS。

## Out of Scope

- 单凭海天线自动确定绝对 Yaw，或新增地标方向拟合。
- 新增设备 PTZ 指令、自动扫描或自动应用校准结果。
- 改写既有截图、正式标注或原始设备采样记录。
- 独立的变倍主点漂移、镜头畸变等光学模型扩展。

## Further Notes

T 补偿手调采用保持原机械校正作用的约定。补偿由 $\delta$ 改为 $\delta'$ 时，更新零位旋转为 $R_0R_x(\delta'-\delta)$，并从该旋转更新表单。设备零位相对旋转仍为单位矩阵。

新增姿态模型的适用性由独立原图验收决定。若随 P/T 或倍率的残差超过复拍与重标水平，先复核姿态模型与光学条件，再决定是否恢复独立光轴旋转或补充观测。
